## 盘点结论

1. **可直接复用的硬资产**：黑箱（金库+监控+库珀办公室三合一）、安保措施章（已有响应规则）、库珀的追逐频谱、金色齿轮动线、西奥的提现门票。改造的一半工作量已经由原模组完成了。
2. **必须新增的**：莱斯特（整张卡）、筹备类场景（原模组没有"搞装备/拉内应"的场景）、分赃与销赃场景、匕首的机制页。
3. **必须删改的**：深度 0 的 5 种入局（改为莱斯特委托）；"追捕库珀"从阶段 3 挪到抢劫夜之后。
4. **最大的空档**：原模组没有"抢劫成功后怎么跑"的内容——撤离与销赃要新写。
