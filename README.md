# 迷雾之城 · 主持人工具（Misty City GM Tool）

单机网页版主持人（MC）工具，用于《迷雾之城》跑团时管理玩家状态、场景与模组信息。
**无需服务器、无需联网**：双击 `迷雾之城主持人工具.html` 即可使用，数据保存在浏览器 localStorage。

## 功能

- **人物卡导入**：解析《迷雾之城》自动卡 1.6 模板（一卡一角色），读取角色名、玩家名、理法/神法主题与问卷名、力量标签 A–J、弱点标签 A–D、团队标签
- **玩家 / 团队状态**：标签「已用 / 上限」计数（上限 = 标签等级，用满自动标「燃尽」）；状态标签同类同色、带 1–5 分级；当前场景与时间、活力、线索、已解锁人物/线索；一键「幕间恢复」
- **场景 / 模组**：场景描述与时间状态、NPC（能力标签 + 状态 + 备注）、场景线索（已发现 / 未发现）、每个场景解锁的人物
- **规则速查 + 效力计算器**：状态等级与叠加、燃尽与恢复、核心动作速查；勾选标签 → 加状态修正 → 掷 2d6 判定

## 文件

| 文件 | 说明 |
| --- | --- |
| `迷雾之城主持人工具.html` | 主程序，单文件，双击即用 |
| `xlsx.full.min.js` | SheetJS，本地内置（离线导入 xlsx 用） |
| `taxonomy.js` | 主题与标签问卷总表（11 理法 + 11 神法主题的力量/弱点题目），供新增主题时选题 |
| `seed.js` | 内置示例模组（2 个示例场景 + 解锁池，**不含玩家角色**，角色需导入人物卡） |
| `示例人物卡_炎.xlsx` | 导入测试用示例卡，结构与真实玩家卡一致 |

## 人物卡读取位置（自动卡 1.6）

- 角色名 `B2`、玩家名 `E2`
- 主题块起始列：`O / X / AG / AP / AY / BH`（每块宽 9 列，共 6 块）
  - 字段统一在「起始列 +2」：行2 类型、行3 主题名（问卷名）、行4 标题、行5 身份/谜题、行6 描述
  - 力量标签为「问题行 + 答案行」成对：答案行 `11,13,15,17,19`（问题行 `10,12,14,16,18` 仅作悬浮提示）
  - 弱点标签答案行 `24,26`（问题行 `23,25`）
- 第 5、6 块位分别为**团队主题**（力量标签并入团队标签）与**附加主题**
- 已按合并单元格取锚点值；空块依据「标题/身份/描述/标签」是否有内容判定

## 注意

数据存在浏览器本地，**换电脑或清缓存会丢**。请在「数据 / 导入」页定期用「导出 JSON 存档」备份。
